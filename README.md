# D4TimeMacro / D4 타임 매크로

Windows x64 · v0.5.38 · 한국어 / English UI

## 한국어
압축을 풀고 D4TimeMacro.exe와 D4TimeMacro.dat를 같은 폴더에 두세요. 상단 **한국어 / English** 버튼에서 표시 언어를 선택하면 다음 실행에도 유지됩니다. 실행 중 언어 변경은 동작을 정지합니다.

대상 프로그램을 먼저 선택하세요. F1 시작, F2 정지, F3/F4를 누르는 동안 좌/우 연속 클릭, F5 자동파티 1회 실행입니다. 자동파티 탭에서 F1을 누르면 키보드·마우스로 전환하며 시작합니다.

**영어 UI와 영어 게임 화면 인식은 별개입니다.** 현재 인식 자료와 안내 스크린샷은 한국어 게임 기준입니다. 영어 게임 화면용 템플릿을 직접 등록하는 기능은 아직 없으며, 영어 게임 인식은 검증되지 않았습니다. 현재 사용하려면 게임 텍스트 언어를 한국어로 설정하세요. UI는 영어로 사용할 수 있습니다. 안내 음성은 한국어입니다.

영어 인식 지원을 위한 스크린샷 준비 방법은 [ENGLISH-GAME-IMAGES.md](ENGLISH-GAME-IMAGES.md)를 참고하세요.

낚시는 Home에 낚시, F에 상호작용을 지정하고 우클릭 기술 칸의 입질 표시를 사용합니다. 민감도는 PC마다 시험해야 하며 개발자 권장은 40입니다. 카운트는 낚아채기 시도 횟수이며 실제 획득 확정 수량이 아닙니다.

자동 라이선스 발급에는 서버 통신이 필요합니다. 선택적 사용 통계와 라이선스 처리는 구분됩니다. 과도한 사용이나 악용으로 발생하는 게임 이용 제한의 책임은 사용자에게 있습니다.

## English
Extract the archive and keep **D4TimeMacro.exe** and **D4TimeMacro.dat** together. Select **한국어 / English** at the top to change the interface language. Your selection is remembered. Changing language stops current actions.

Select the target application first. F1 starts; F2 stops. Hold F3/F4 for repeated left/right clicks. F5 runs one party sequence. F1 from Auto Party switches to Keyboard & Mouse and starts it.

**English UI does not mean English game recognition.** Recognition references and guide screenshots currently use the Korean game UI. There is no custom English template import interface yet. English game recognition is unverified. For the current recognition features, use Korean game text while keeping this program's UI in English. Voice announcements remain Korean.

See [ENGLISH-GAME-IMAGES.md](ENGLISH-GAME-IMAGES.md) for preparing English reference images for future support.

Fishing requires Home bound to fishing and F to interaction. It detects the bite indicator in the right-click skill slot. Test sensitivity on your own PC; the developer recommendation is 40. Counters record reel-in attempts, not confirmed loot.

Automatic license issuance requires a server connection. Optional usage statistics are separate from license processing. You are responsible for game restrictions resulting from excessive use or misuse.
